# Robot kid auditions

Matt heard the neutral candidates as female and the boyish candidates as adult
men. His intended direction is a cute robot kid. Warm - soft robot remains
his provisional frontrunner, preserved exactly alongside every earlier take.

Three new continuous Qwen VoiceDesign takes explicitly request a prepubescent
boy vocal identity, with different personalities and light robot effects:

- Robot kid - gentle Chip: soft, thoughtful, rounded vowels; no pitch shift.
- Robot kid - curious Pixel: bright and playful; +0.25 semitone.
- Robot kid - mellow Widget: light, softly androgynous robot-child direction;
  no pitch shift, slightly more electronic texture.

These are synthesis prompts to audition, not assurances about perceived age
or gender. The dry takes are retained. `qwen-kids.json` records each prompt,
effects and full generation-plus-processing time. All use the same script.

Reproduce in the Python 3.12 audition environment, using a fresh directory
with the original `qwen.json` and the helper/FX modules in repository layout:

```sh
python tools/audition_robot_voices.py samples --round kids
python tools/build_voice_audition_page.py samples
```
